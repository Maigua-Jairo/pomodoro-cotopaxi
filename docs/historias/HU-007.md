# HU-007: Detener una fase y pasar a la siguiente

**Identificador / ID:** HU-007  
**Usuario:** Estudiante  
**Nombre de la Historia:** Detener una fase y pasar a la siguiente  
**Prioridad para el negocio:** Media  
**Riesgo para desarrollo:** Medio  

**Descripción:** Como estudiante, quiero detener el estudio o el descanso en curso cuando lo necesite, para pasar a la otra fase sin esperar a que termine el tiempo.

## Criterios de aceptación
### Escenario: Detener el estudio
Dado que inicié un tiempo de estudio  
Cuando presiono «Detener» y acepto la confirmación  
Entonces la aplicación muestra el temporizador de descanso en pausa, listo para iniciarlo  

### Escenario: Detener el descanso
Dado que inicié un descanso  
Cuando presiono «Detener» y acepto la confirmación  
Entonces la aplicación vuelve al temporizador de estudio en estado pausado  

### Escenario: Cambiar de opinión al detener
Dado que presioné «Detener»  
Cuando cancelo la confirmación  
Entonces la fase sigue exactamente como estaba
